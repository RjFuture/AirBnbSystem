# AirBnB System

A monolithic clone of an Airbnb-style property booking platform, built to practice real-world backend engineering patterns using Spring Boot.

## Purpose
This is a self-directed learning project to strengthen hands-on Spring Boot/Java backend skills ahead of interviews for Backend Java/Spring Boot Developer roles.

## Tech Stack
- Java, Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Spring Security (JWT-based authentication)
- Maven
